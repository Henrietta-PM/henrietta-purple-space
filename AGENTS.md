# Project rules

- Serve the fixed downloadable CV through a Lovable Assets pointer so the uploaded PDF stays outside source control.
- Preserve existing portfolio experience and defer conflicting resume facts to the owner instead of silently replacing them.
- The Mac and iPhone style experience is the site home at /; classic pages stay reachable by URL but nothing in the new experience, sitemap or llms.txt links to them, and OS apps reuse the classic components' exported data so content is never duplicated.
- Pick the Mac or iPhone interface by viewport width with the shared mobile hook, and share app content between both shells.
- App organization uses a shared validated visitor-local layout and dnd-kit sensors for both shells; keep layout changes separate from portfolio content and use category-based folder names so rearranging never modifies owner data.
- Share exploration notifications between both OS shells, using their existing app launch callbacks; keep them local and start phone notifications only after the lock screen closes so they never require browser permission or interrupt entry.
- Camera and Photos share a visitor guestbook; anonymous submissions and private reports go through a validated edge function with atomic network throttling, and private photo storage is accessed only through service-generated signed URLs to keep write access out of the browser.
- Keep the existing letter launcher ID for saved layouts, but present it as Notes with shared note content; pass a note selection from widgets and note shortcuts so normal app launches open the note list.
- Notes uses single-screen folder/list/reader navigation on phone and independently scrollable folder/list/reader columns on Mac; retain working reader actions, allow visitor edits and highlights saved only in their own browser, and omit owner-only authoring tools so shared note content never changes.
- Messages pins the original testimonials and lists public visitor messages from the guestbook function (kind message, same throttling and reporting), shared between phone and Mac; never invent message dates or replies.
- Shared Apple app navigation provides phone tab bars and desktop sidebars, with app-specific content kept separate so portfolio facts and visitor actions remain unchanged.
- My Journey is a keyless Leaflet/OpenStreetMap map showing only owner-confirmed places, with visitor city lookup done in the browser via Open-Meteo geocoding, so no location is invented and no key is needed.
- Render a lightweight lock-screen fallback while OS app code loads and initialize the shared viewport hook synchronously, so phones never first mount the desktop shell; both shells start locked and defer exploration notifications until entry.
- Mail shares its composer with Contacts, keeps drafts and sent copies visitor-local, and uses a validated contact function with the existing email provider and atomic network throttle; never expose the owner's inbox or store private mail in the public guestbook.
- When adding Mail to saved app layouts, insert only the missing Mail tile into its default zone while preserving validated visitor folders and positions so existing organization is not reset.
